# Student Academic Tracker

Stack: HTML, CSS, JavaScript, PHP, MySQL, XAMPP, Chart.js, Python.

## Installation
1. Copy the `student-academic-tracker` folder into XAMPP `htdocs`.
2. Import `student_tracker.sql` into phpMyAdmin.
3. Open `http://localhost/student-academic-tracker/`.
4. Demo admin: username `admin`, password `admin123`.

This package is a clean working foundation. Academic CRUD modules and Chart.js reports can be expanded without changing the core login/database structure.
